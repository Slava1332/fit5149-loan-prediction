# FIT5149 S2 2026 — Предсказание одобренной суммы кредита

## Описание проекта

Данный репозиторий содержит проект по машинному обучению, выполненный в рамках **FIT5149 S2 2026 Assessment 1**.

Цель проекта — предсказать сумму кредита, одобренную для каждой заявки.

Целевая переменная:

```text
sanctioned_amount_aud
```

Весь процесс моделирования реализован в одном Jupyter Notebook:

```text
modeling.ipynb
```

## Постановка задачи

Целевая переменная содержит значительное количество нулевых значений. Поэтому задача рассматривается не только как обычная задача регрессии.

В проекте используется гибридный подход, который учитывает вероятность того, что заявка получит нулевую одобренную сумму, а также размер положительной одобренной суммы.

Основные компоненты подхода:

* классификация нулевых и положительных значений;
* моделирование отношения одобренной суммы к запрошенной;
* условная регрессия для положительных значений;
* прямая регрессия целевой переменной;
* ансамблирование моделей;
* калибровка вероятностей;
* подбор порога предсказания.

## Данные

Данные предоставляются в рамках Kaggle-соревнования **FIT5149 S2 2026 Assessment 1**.

Исходные данные Kaggle не включены в этот репозиторий.

data/

## Методология

### 1. Исследовательский анализ данных

В notebook выполняется:

* анализ размера и структуры датасета;
* просмотр описательной статистики;
* анализ пропущенных значений;
* исследование распределения целевой переменной;
* анализ доли нулевых значений;
* визуализация основных характеристик данных.

### 2. Предобработка данных

Выполняются следующие операции:

* обработка специальных значений `-999`;
* обработка некорректных отрицательных финансовых значений;
* удаление идентификаторов и технических признаков;
* преобразование даты заявки;
* создание дополнительных признаков, связанных с пропущенными значениями.

### 3. Feature Engineering

В проекте создаются дополнительные признаки, включая:

* преобразования возраста;
* преобразования кредитного рейтинга;
* логарифмические финансовые признаки;
* отношение дохода к запрошенной сумме;
* отношение платежей к доходу;
* признаки долговой нагрузки;
* признаки Loan-to-Value;
* соотношения стоимости недвижимости и дохода;
* взаимодействия между кредитным рейтингом, доходом, запрошенной суммой и стоимостью недвижимости.

### 4. Кодирование категориальных признаков

Категориальные переменные преобразуются с помощью One-Hot Encoding.

После кодирования пространства признаков обучающей, валидационной и тестовой выборок выравниваются.

Для моделирования используется XGBoost.

## Используемые модели

### Классификация нулевых и положительных значений

XGBoost-классификатор оценивает вероятность:

```text
P(sanctioned_amount_aud > 0 | X)
```

Эта вероятность используется в дальнейшем при построении итогового предсказания.

### Модель отношения сумм

Для положительных наблюдений моделируется отношение:

```text
sanctioned_amount_aud / requested_amount_aud
```

После этого полученное отношение используется для формирования предсказания одобренной суммы.

### Условная логарифмическая регрессия

Для наблюдений с положительной одобренной суммой обучается отдельная XGBoost-модель.

В качестве целевой переменной используется:

```text
log1p(sanctioned_amount_aud)
```

После предсказания выполняется обратное преобразование с помощью `expm1`.

### Прямая регрессия

Дополнительно обучается XGBoost-регрессор, который напрямую предсказывает:

```text
sanctioned_amount_aud
```

## Ансамбль моделей

Финальное предсказание формируется на основе нескольких моделей:

1. классификатор × модель отношения сумм;
2. классификатор × условная логарифмическая регрессия;
3. прямая регрессия.

Вероятности классификатора дополнительно калибруются.

После этого подбираются веса моделей, масштабирование итогового предсказания и порог, используемый для обработки малых предсказаний.

## Оценка качества

Основной метрикой соревнования является **RMSE (Root Mean Squared Error)**.

Также используются дополнительные показатели:

* MAE;
* ROC-AUC для задачи классификации;
* RMSE для положительных наблюдений;

Результаты экспериментов и сравнение моделей представлены в `modeling.ipynb`.

## Ограничения

Исходные данные Kaggle и файлы с результатами соревнования не хранятся в репозитории.

Валидационная выборка используется не только для оценки, но и для выбора параметров ансамбля, калибровки, масштабирования и порога. Поэтому полученный validation RMSE следует рассматривать как оценку, использованную в процессе выбора модели, а не как полностью независимую оценку на скрытом тестовом наборе.
