# Данные

Данные для проекта предоставляются в рамках соревнования **FIT5149 S2 2026 Assessment 1 — Sanctioned Loan Amount Prediction** на Kaggle.

Исходные файлы соревнования **не включены в данный GitHub-репозиторий**.

Для запуска `modeling.ipynb` необходимо скачать данные соревнования и поместить следующие файлы в эту папку:

```text
data/
    training_set.csv
    kaggle_test_X.csv
    sample_submission.csv
```

### Назначение файлов

* `training_set.csv` — обучающая выборка, содержащая целевую переменную `sanctioned_amount_aud`.
* `kaggle_test_X.csv` — тестовая выборка, для которой необходимо получить предсказания.
* `sample_submission.csv` — шаблон файла для формирования итогового submission.

В `modeling.ipynb` эти файлы загружаются из следующих путей:

```text
data/training_set.csv
data/kaggle_test_X.csv
data/sample_submission.csv
```

После размещения файлов в данной директории notebook можно запускать последовательно сверху вниз.

### Ограничение на распространение данных

Файлы с данными соревнования не хранятся в репозитории. Согласно правилам соревнования, Competition Data предназначены для участия в соревновании и академического обучения и не должны передаваться или публиковаться лицам, которые не участвуют в соревновании.

Данные необходимо получать непосредственно через страницу соревнования Kaggle.
